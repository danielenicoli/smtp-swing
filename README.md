# Realizzazione di un client email SMTP con Swing
## Indicazioni per la realizzazione del progetto
- Scegliere un progetto di tipo Maven all'atto della creazione con l'IDE
- Per la generazione della password, fare riferimento a [questo link](https://moodle.nicoli.dev/mod/url/view.php?id=607)
- Ricordarsi di non condividere il file .env che contiene la vostra password SMTP
- Ricordarsi di revocare la password generata quando non è più necessaria
- Ricordarsi di usare i mezzi tecnologici solo per gli scopi consentiti
